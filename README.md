### Install (Windows)
Windows 10 or 11, 64-bit. For a zip: right-click it and choose Extract All, then open the folder. If you see `install.ps1`, right-click it and choose Run with PowerShell (it adds Start Menu and Desktop shortcuts and doesn't need admin). If you see a Setup .exe, run that. Some apps are a self-contained .exe with nothing to install: just double-click it. If Windows says it protected your PC, click More info, then Run anyway.

Each release lists the SHA-256 of its file so you can check the download. Older versions stay on the [Releases](https://github.com/ChiniakVictor/sovereign-apps/releases) page.
