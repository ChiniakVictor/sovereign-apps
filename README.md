## Install
Windows 10 or 11, 64-bit. Download the zip, right-click it and choose Extract All, open the folder, right-click `install.ps1` and choose Run with PowerShell. It adds Start Menu and Desktop shortcuts and doesn't need admin. If Windows says it protected your PC, click More info, then Run anyway.

Each release lists the SHA-256 of its zip so you can check the download.
